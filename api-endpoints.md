# API Endpoint Documentation

> Baseline reference for the React web app team consuming the `exam-generator` REST API.

## Authentication

Every request must include the deployment-specific API key in the `x-api-key` header:

```http
x-api-key: {EXAM_GENERATOR_API_KEY}
```

The API uses API Gateway request authorization with CORS enabled. There is no user/session authentication; the key is shared by the web app.

## Base URL and versioning

The API is served from an API Gateway stage. Example production URL format:

```
https://{api-id}.execute-api.{region}.amazonaws.com/{stage}
```

All endpoints are prefixed with `/v1`.

Example:

```
GET https://api.example.com/v1/certifications
```

All requests and responses use `Content-Type: application/json` unless otherwise noted.

## Error response format

All error responses share this JSON shape:

```json
{
  "error": "CamelCaseErrorCode",
  "message": "Human-readable description"
}
```

| Error code | HTTP status | Typical cause |
| --- | --- | --- |
| `InvalidRequest` | 400 | Malformed body, invalid query params, or invalid config values (e.g. distributions not summing to their required totals). |
| `NotFound` | 404 | Resource does not exist. |
| `ExamNotReady` | 409 | Exam exists but is not in `READY` status. |
| `Conflict` | 409 | Duplicate `provider` + `code` or immutable fields changed. |
| `InternalError` | 500 | Unexpected server error. |

## Endpoints

### Health check

#### `GET /v1/health`

Simple liveness check.

**Response — 200 OK**

```json
{
  "status": "ok"
}
```

### Create certification

#### `POST /v1/certifications`

Registers a new certification in the catalog. The `id` is generated by the backend; domain topic IDs are also system-generated on create. `provider` and `code` are immutable and must be unique together.

**Request body**

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `provider` | `string` enum (`aws`, `azure`, `gcp`) | yes | Immutable after creation. |
| `code` | `string` | yes | Provider-specific exam code. Immutable after creation. |
| `name` | `string` | yes | Human-readable title. |
| `description` | `string` | yes | Short description. |
| `isActive` | `boolean` | yes | Whether it appears in public listings. |
| `config.questionCount` | `integer` | yes | `1`–`100`. |
| `config.difficultyDistribution` | `object` | yes | `easy`, `medium`, `hard` integers that must sum to `100`. |
| `config.domains` | `array` | yes | At least one domain object. Domain weights must sum to `100`. |

Each domain in `config.domains`:

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `name` | `string` | yes | Domain name. |
| `weight` | `integer` | yes | Integer percentage weight (`>= 1`). All domain weights sum to `100`. |
| `topics` | `string[]` | yes | Topic names. IDs are system-generated on create/update. |

**Example request**

```json
{
  "provider": "aws",
  "code": "CLF-C02",
  "name": "AWS Certified Cloud Practitioner",
  "description": "Foundational AWS cloud certification.",
  "isActive": true,
  "config": {
    "questionCount": 10,
    "difficultyDistribution": { "easy": 40, "medium": 40, "hard": 20 },
    "domains": [
      {
        "name": "Cloud Concepts",
        "weight": 40,
        "topics": ["Cloud Value Proposition", "AWS Global Infrastructure"]
      },
      {
        "name": "Technology",
        "weight": 30,
        "topics": ["Compute", "Storage", "Networking"]
      }
    ]
  }
}
```

**Response — 201 Created**

```json
{
  "id": "11111111-1111-1111-1111-111111111111",
  "provider": "aws",
  "code": "CLF-C02",
  "name": "AWS Certified Cloud Practitioner",
  "description": "Foundational AWS cloud certification.",
  "isActive": true,
  "config": {
    "questionCount": 10,
    "difficultyDistribution": { "easy": 40, "medium": 40, "hard": 20 },
    "domains": [
      {
        "id": "44444444-4444-4444-4444-444444444444",
        "name": "Cloud Concepts",
        "weight": 40,
        "topics": [
          { "id": "55555555-5555-5555-5555-555555555555", "name": "Cloud Value Proposition" },
          { "id": "66666666-6666-6666-6666-666666666666", "name": "AWS Global Infrastructure" }
        ]
      }
    ]
  }
}
```

**Errors**: `400 InvalidRequest` (missing fields, or `difficultyDistribution`/domain weights that don't sum to their required totals), `409 Conflict` (duplicate `provider` + `code`).

### Get a certification

#### `GET /v1/certifications/{id}`

### Update a certification

#### `PUT /v1/certifications/{id}`

Updates mutable fields (`name`, `description`, `isActive`, `config`). `provider` and `code` are immutable and may not be present in the body. Topic IDs are regenerated as needed on update.

**Request body**

Same shape as the create request's config-driven fields, but without `provider` and `code`. `name`, `description`, `isActive`, and `config` are all required.

**Example request**

```json
{
  "name": "AWS Certified Cloud Practitioner (Updated)",
  "description": "Updated description.",
  "isActive": true,
  "config": {
    "questionCount": 40,
    "difficultyDistribution": { "easy": 20, "medium": 50, "hard": 30 },
    "domains": [
      {
        "name": "Cloud Concepts",
        "weight": 40,
        "topics": ["Cloud Value Proposition", "AWS Global Infrastructure"]
      },
      {
        "name": "Technology",
        "weight": 30,
        "topics": ["Compute", "Storage", "Networking"]
      }
    ]
  }
}
```

**Response — 200 OK**

Same certification shape as `POST /v1/certifications`.

**Errors**: `400 InvalidRequest` (missing fields or immutable fields present), `404 NotFound`.

### Request exam generation

#### `POST /v1/exams`

Starts an asynchronous exam generation job. Returns the exam ID and initial `GENERATING` status.

**Request body**

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `certificationId` | `string` (UUID) | yes | Must be an active certification. |

**Example request**

```json
{
  "certificationId": "11111111-1111-1111-1111-111111111111"
}
```

**Response — 201 Created**

```json
{
  "id": "22222222-2222-2222-2222-222222222222",
  "status": "GENERATING"
}
```

**Errors**: `400 InvalidRequest` (missing or invalid UUID), `404 NotFound` (certification unknown or inactive).

### List exams

#### `GET /v1/exams`

Returns exam metadata rows. Defaults to `status=READY`.

**Query parameters**

| Parameter | Type | Default | Notes |
| --- | --- | --- | --- |
| `status` | `GENERATING`, `READY`, `FAILED` | `READY` | Filter by status. |
| `provider` | `aws`, `azure`, `gcp` | — | Filter by provider. |
| `certificationId` | UUID | — | Filter by certification. |
| `limit` | `integer` | `20` | Max `100`. |
| `cursor` | `string` | — | Base64-encoded opaque cursor from a previous response. |

**Response — 200 OK**

```json
{
  "items": [
    {
      "id": "22222222-2222-2222-2222-222222222222",
      "certificationId": "11111111-1111-1111-1111-111111111111",
      "provider": "aws",
      "title": "AWS Certified Cloud Practitioner - Practice Exam 2026-07-28T12:00:00.000Z",
      "status": "READY",
      "createdAt": "2026-07-28T12:00:00.000Z",
      "finishedAt": "2026-07-28T12:00:45.000Z",
      "s3KeyJson": "exams/22222222-2222-2222-2222-222222222222/exam.json",
      "s3KeyPdf": "exams/22222222-2222-2222-2222-222222222222/exam.pdf"
    }
  ],
  "cursor": {
    "nextCursor": null,
    "hasNextPage": false
  }
}
```

`nextCursor` is an opaque base64 string. Pass it as the `cursor` query parameter to fetch the next page. `hasNextPage` indicates whether another page exists.

**Errors**: `400 InvalidRequest` (invalid query parameters).

### Get exam status

#### `GET /v1/exams/{id}/status`

Lightweight endpoint for polling. Always returns the current status, even while `GENERATING` or `FAILED`.

**Response — 200 OK**

```json
{
  "id": "22222222-2222-2222-2222-222222222222",
  "status": "GENERATING",
  "createdAt": "2026-07-28T12:00:00.000Z",
  "finishedAt": null
}
```

Status values:

- `GENERATING` — generator is working.
- `READY` — exam is ready for review/download.
- `FAILED` — generation failed; request a new exam.

**Errors**: `400 InvalidRequest` (bad UUID), `404 NotFound`.

### Get PDF download URL

#### `GET /v1/exams/{id}/download`

Returns a time-limited presigned URL for the generated PDF. Only available when `status === "READY"`.

**Response — 200 OK**

```json
{
  "downloadUrl": "https://s3.amazonaws.com/...",
  "expiresAt": "2026-07-28T12:05:00.000Z"
}
```

The URL expires after a short window (default 5 minutes). Fetch it on user action and immediately redirect or start the download.

**Errors**: `400 InvalidRequest` (bad UUID), `404 NotFound`, `409 ExamNotReady`.

---

### Delete an exam

#### `DELETE /v1/exams/{id}`

Deletes the exam metadata row and any S3 artifacts. Returns an empty body on success.

**Response — 204 No Content**

No body.

**Errors**: `400 InvalidRequest` (bad UUID), `404 NotFound`.
