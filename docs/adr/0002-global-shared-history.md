# History is a global, shared list of exams

Status: superseded by ADR 0011.

The web app will call `GET /v1/exams` and present the returned list as a global history of all ready exams. Because the backend has no user scoping or authentication, any user sees exams generated by all users. The Delete action in the UI will call `DELETE /v1/exams/{id}`, which removes the exam and its S3 artifacts for everyone. We will not visually distinguish exams created in the current browser from exams created elsewhere.

We chose this over a local-only history because it matches the backend API directly and avoids client-side bookkeeping. It fits an MVP where the audience is trusted or small. If the app becomes public or multi-tenant, we will need to add authentication and per-user scoping to the backend before this design is safe.
