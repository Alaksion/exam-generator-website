# Public marketing landing page at the root; sign-in moves to `/sign-in`

The unauth branch of `App` now renders a full-width public marketing **Landing** page at `/` for cold visitors, and the sign-in card moves off the root index onto its own `/sign-in` route so the auth-card routes can keep their centered-card wrapper. Authenticated users bypass the public surface entirely and land in the existing UiShell app (Catalog at `/`). We chose a dedicated marketing page over reusing the auth card or merging the public and authenticated surfaces because the product's growth goal is converting cold traffic, and the existing centered-card wrapper cannot host a full-bleed editorial page. The retheme rules from ADR 0008 still govern: the Landing is flat and bordered with zero ambient shadows, using Fraunces display type, ink-primary accents, color/typography hierarchy, and one restrained two-tone cool-neutral SVG motif — not shadcn defaults or box-shadow. Copy pitches the product's real mechanics (on-demand Exam generation, per-domain Breakdown, Score, Review, Download) plus the benefit of guided mock-exam study over reading cloud documentation; `index.html` gains a meta description for indexability.
